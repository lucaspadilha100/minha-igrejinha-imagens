# Imagens do Minha Igrejinha

Fotos e pinturas dos santos usadas pelo app, servidas pelo Cloudflare Pages.
O crédito de cada imagem (obra, autor, licença e origem) está na ficha do santo, no repositório do app, e aparece na tela Créditos.

- Arquivo novo entra com nome novo: o cache é de um ano.
- `_headers` libera o acesso de outros endereços (o app desenha o santinho e o cartaz com a foto).
